# ctf-writeups
A collection of technical write-ups documenting Capture The Flag (CTF) challenges I've solved while developing my skills in offensive security.

Each write-up focuses on the reasoning behind the solution, the techniques used during the investigation, and the underlying security concepts.

---

### Categories
- Web: Web vulnerabilities, authentication, access control, and application logic.
- Pwn: Binary exploitation and memory corruption.
- Crypto: Cryptographic weaknesses and mathematical analysis.
- Forensics: Artifact analysis and digital investigation.
- Misc: Other challenges and techniques.
- Write-up Structure

---

### Depending on the challenge, write-ups may include:
- Challenge overview
- Initial analysis and reconnaissance
- Investigation and technical reasoning
- Vulnerability analysis or root cause
- Exploitation and solution
- Lessons learned and relevant references

---

### Competitions
See the directories in this repository to browse individual competitions and the write-ups of their respective challenges.

---

### Disclaimer
All content is intended for educational purposes. Write-ups are published in accordance with the relevant competition rules and disclosure policies. Sensitive challenge materials, flags, and solutions are omitted where publication is prohibited.
